# Exercícios da Apostila de POO em Java

Este repositório reúne minhas resoluções dos exercícios da apostila de Programação Orientada a Objetos (POO) em Java.

## Conteúdos praticados

- Criação de classes e objetos
- Definição de atributos e métodos
- Inicialização de objetos com construtores
- Encapsulamento com modificadores de acesso

## Como executar

1. No GitHub, clique em **Code → Download ZIP** e extraia os arquivos.
2. Abra a pasta do projeto no IntelliJ IDEA.
3. Abra a classe com o método `main` do exercício e clique em **Run**.
